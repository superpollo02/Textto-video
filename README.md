# Textto-video (Document-to-Video Engine)

AI-powered platform to transform documents (PDF, Word, PowerPoint, Excel, CSV, Markdown, TXT) and web URLs into narrated, animated videos.

## Features
- **Multi-Format Document Ingestion**: Upload PDFs, DOCX, PPTX, XLSX spreadsheets, CSV data tables, and Markdown notes.
- **Document Video Modes**:
  - **Executive Summary** (~30–90s): High-impact key points, takeaways, and punchy pacing.
  - **Step-by-Step Explainer** (~1–3 min): Educational breakdown of complex concepts.
  - **Full Presentation** (~3–8 min): Section-by-section slide narrative.
  - **Data Report & Charts** (~1–4 min): Emphasizes metrics, tables, and data visualizations.
- **Multiple Aspect Ratios**: 16:9 widescreen, 9:16 portrait, and 1:1 square.
- **AI Script & Scene Generation**: Automated transcription, table extraction, and Remotion-powered video composition.
